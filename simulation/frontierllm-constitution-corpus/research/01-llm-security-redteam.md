# Lane 01 — LLM-specific security & red-team test corpora

Research date: 2026-09-05. Every licence below was checked by fetching the actual
repository `LICENSE` file, the Hugging Face dataset card, or the repo README. Where a
licence could not be confirmed from a primary artifact it is marked **UNVERIFIED** and no
guess is offered.

Out of scope (covered by the earlier survey, not re-derived): AgentDojo, InjecAgent,
CyberSecEval/PurpleLlama, Juliet/SARD, CWE, CVEfixes, OWASP standards, OWASP Benchmark.

## 0. How this lane maps onto the compliance corpus

The target corpus case shape is:

```
(case_id, provisions_engaged[], factor_facts{bool}, expected_disposition)
```

None of the sources below are compliance cases. They are **adversarial stimuli** plus, in
the better ones, **ground-truth safety labels**. Two distinct reuse paths exist, and they
should not be confused:

1. **Fact-generator path** — the dataset is run against a candidate change (a new model
   checkpoint, a new tool, a new serving config) and the *result* becomes a boolean factor
   fact in a case (`asr_above_threshold`, `refusal_rate_regressed`, `injection_bypassed_filter`).
   The dataset is a measurement instrument, not corpus content. This works even for
   REFERENCE-ONLY / NC data, because nothing is redistributed.
2. **Vendored-fixture path** — a small, curated slice is copied into the corpus repo as the
   literal stimulus text of a case, so the case is self-contained and reproducible. This
   requires a permissive licence *and* content that is safe to ship.

Almost everything in this lane is path 1. Only a short list qualifies for path 2, and even
within that list some items should be excluded on content grounds regardless of licence.

## 9. Recommended shape

Build the corpus around a **three-layer split**, following the pattern that PyRIT, Inspect and HELM all independently converged on:

1. **Vendored layer** (in-repo, permissive): XSTest, BBQ, SimpleSafetyTests, Do-Not-Answer, AILuminate demo (minus `cse`), deepset/prompt-injections, Forbidden Question Set, SafetyBench, BackdoorLLM poisoned samples, a stratified LLMail-Inject sample. All CC-BY-4.0 / CC-BY-2.0 / Apache-2.0 / MIT, all verified above.
2. **Fetched layer** (pointers + run-time download via PyRIT / inspect_evals): HarmBench, AdvBench, StrongREJECT prompts, WildGuardMix, SORRY-Bench, ToxiGen, BeaverTails. No licence passes through the repo.
3. **Generated layer** (your own fixtures, taxonomy borrowed): the entire insecure-output-handling provision, plus HolisticBias-style templated bias probes regenerated from your own descriptor list to avoid the SA obligation.

Model the case record on **LLMail-Inject's `objectives` vector** and **AILuminate's CSV columns** — between them they already contain every field the target schema needs.
